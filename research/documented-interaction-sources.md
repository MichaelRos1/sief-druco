# Sources for documented drug-pair interactions without a DrugBank licence

Ticket: #13 (map #1). Serves RQ3 (`1.4`) and the novelty check (`7.7`): for a top-burden **drug pair**, is the interaction "already documented"?

Researched 2026-10-27 (first pass, web access intermittent) and re-checked 2026-10-28 against the sources themselves (second pass). Each claim is marked:

- **[verified: <source>]** checked against the named primary page, file, paper or live API response. The URL is in the per-source section and in "Sources". Claims marked **[V]** were verified in the first pass (2026-10-27) and are kept as they were.
- **[unverified]** not checked against a primary source. Do not rely on it without checking.
- **Corrected:** marks a place where a first-pass claim was wrong.

No `[K]` (prior-knowledge) claims remain.

## Answer in one paragraph

Without a DrugBank licence, the strongest free reference is **DDInter** (curated, pair-level, severity level + mechanism text on the web pages, CSV download, **CC BY-NC-SA 4.0** stated on its own terms page). Its bulk CSVs are the 2021 (1.0) data, also for DDInter 2.0, and the full set has **14 ATC files, including C (cardiovascular) and N (nervous system)**. The download page lists only 8 of them. For **side-effect-level** "documented" evidence, **CRESCENDDI** (drug pair + MedDRA adverse event, from BNF, the French ANSM Thesaurus and Micromedex; **CC0** on figshare) is the only clinically curated open set found, but it is small (454 drugs, 4,971 distinct pairs). **TWOSIDES / nSIDES** gives side-effect-level pairs but is mined from FAERS, the *same kind of source Decagon was built from* (`3.4.1`), so it cannot serve as independent "documented" evidence. Its data files have no stated licence. The **ONC high-priority list** is tiny (15 class-level pairs) and useful only as a sanity check (`7.1`). The **NLM RxNav interaction API is gone** (discontinued 2 January 2024, per NLM's FAQ). The RxNorm name/ID APIs still work. **SIDER** has no pair data and is CC BY-SA 4.0 (not NC, as first written). **Drugs.com** forbids automated extraction. **KEGG** REST is for academic users only, max 3 calls/s; bulk FTP is a paid subscription.

## Per source

### DrugBank: what is free without a licence
- The release page lists DrugBank **5.1.22 (2026-06-27)** and states that "All Academic DrugBank dataset downloads are temporarily paused". [V; re-verified 2026-10-28] <https://go.drugbank.com/releases/latest>
- Academic files (full XML with interactions, structures, target links) are **CC BY-NC 4.0** and need a free account plus eligibility (students, professors, research associates at an academic institution, non-commercial). [V] Same page.
- **Open Data (CC0)**: *DrugBank Vocabulary* (CSV, 1.12 MB, "DrugBank identifiers, names, and synonyms") and *DrugBank Structures* (SDF, 5.16 MB). Neither contains drug–drug interactions. [V; sizes and wording verified: same page, 2026-10-28]
- **New (2026-10-28):** both Open Data download buttons now read "Temporarily unavailable", and `curl -I -L https://go.drugbank.com/releases/5-1-22/downloads/all-drugbank-vocabulary` returns `HTTP/2 403`. [verified: same page + request] The CC0 vocabulary is therefore not downloadable right now either.
- So "free academic access" still means applying for the academic licence; without it, DrugBank DDIs are unavailable. The CC0 vocabulary would be a name/synonym → DrugBank-ID bridge once downloads return. Meanwhile, RxNav maps DrugBank IDs to RxCUIs live (see RxNorm below).
- Coverage of the licensed DDI data and its row format (pair + templated sentence) [unverified].

### DDInter (1.0 and 2.0)
- 1.0: 1,833 approved drugs, 236,834 associations from literature and drug labels; each has mechanism description, management, alternatives; last update 2020-09-04. [V] <https://ddinter.scbdd.com/>
- **Licence (resolved):** DDInter's own terms page says: "The DDInter data is made available under a Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International license." It adds that content may be printed or downloaded "for your own personal, non-commercial, informational or scholarly use". The DDInter 2.0 terms page has the same wording. [verified: <https://ddinter.scbdd.com/terms/>, <https://ddinter2.scbdd.com/terms/>] The footer "All Rights Reserved" is a site copyright line. The first-pass reliance on the third-party repo <https://github.com/mnarayan1/DDInter> is no longer needed.
- **Download page (both sites):** lists 8 CSVs, `ddinter_downloads_code_{A,B,D,H,L,P,R,V}.csv`, sizes 317.5 KB (P) to 3.9 MB (L). [verified: <https://ddinter.scbdd.com/download/>, <https://ddinter2.scbdd.com/download/>]
- **Corrected: C and N files do exist.** A HEAD request on `https://ddinter.scbdd.com/static/media/download/ddinter_downloads_code_<X>.csv` returns HTTP 200 for **all 14 ATC first-level letters** (A, B, C, D, G, H, J, L, M, N, P, R, S, V). A non-ATC letter (`_X.csv`) returns 404. So the server is not answering 200 to everything. Sizes (bytes): A 3,343,434; B 867,726; **C 3,453,462**; D 1,520,704; G 1,994,473; H 705,088; J 2,554,201; L 3,885,702; M 1,271,889; **N 5,218,194**; P 317,460; R 1,793,766; S 1,932,541; V 700,777. All last modified 2021-06-26. [verified: HEAD requests, 2026-10-28] The first-pass claim "no C or N file" was based only on the download page's listing, which omits C, G, J, M, N, S.
- **C file checked:** downloaded (3.45 MB). It has 60,454 rows: Major 6,316, Moderate 35,606, Minor 2,774, Unknown 15,758. It contains e.g. `DDInter79,Amlodipine,DDInter1675,Simvastatin,Major`. [verified: file] The N file (5.2 MB) was not downloaded (over the 5 MB rule; see Blockers).
- **Columns (resolved):** `DDInterID_A,Drug_A,DDInterID_B,Drug_B,Level`; Level ∈ {Major, Moderate, Minor, Unknown}. Names with commas are quoted. [verified: B file (15,140 rows) and C file] Files are grouped by "interaction involving <ATC class> drugs", so a pair can appear in more than one file. Deduplicate across files.
- **DDInter 2.0 download (resolved):** the 2.0 site serves the same 14 file names with **identical byte sizes**. B and C have **identical MD5** to the 1.0 copies (B `3bfcadec…`, C `c15c0264…`). The 2.0 copies are only re-uploaded (last modified 2024-05-21). [verified: HEAD + MD5] So **no bulk download of the 2.0 data (302,516 records, new drug-food/disease data) was found**; 2.0 content is web-only. The 2.0 paper's data-availability statement says only "DDInter 2.0 is freely accessible at https://ddinter2.scbdd.com". [verified: PMC11701621]
- 2.0: Tian et al., NAR 2025, 53(D1):D1356–D1362, doi:10.1093/nar/gkae726. 2,310 drugs (2,122 distinct), 302,516 DDI records, 8,398 mechanism/management descriptions, plus drug–food, 8,359 drug–disease, 6,033 therapeutic duplications; curated by pharmacists. [V; re-verified in full text <https://europepmc.org/article/PMC/PMC11701621>] The paper's comparison table gives 1,972 drugs for 1.0, while the 1.0 home page says 1,833 approved drugs. Data last updated 2024-05-14 per Database Commons. [V] <https://ngdc.cncb.ac.cn/databasecommons/database/id/7473>
- **ID system (resolved):** both versions use the same `DDInter<n>` IDs. Example: `DDInter1675` is simvastatin on both sites and links to DrugBank `DB00641`. 1.0 drug pages link DrugBank, ChEMBL and PubChem **CID** (54454). 2.0 drug pages link DrugBank, ChEMBL, KEGG and PubChem **SID** (46508654). [verified: <https://ddinter.scbdd.com/ddinter/drug-detail/DDInter1675/>, <https://ddinter2.scbdd.com/server/drug-detail/DDInter1675/>]
- Granularity: **pair-level with severity**; the clinical effect is free text (mechanism), not a coded side effect.
- ID mapping to Decagon: DDInter ID → DrugBank ID (drug page) → RxCUI via RxNav `rxcui.json?idtype=DRUGBANK&id=DB00641` (returns 36567, live) [verified: RxNav]; or → PubChem CID (1.0 drug page) → STITCH. Whether Decagon's STITCH IDs map cleanly from PubChem CIDs [unverified].

### CRESCENDDI
- Kontsioti, Maskell, Dutta, Pirmohamed, "A reference set of clinically relevant adverse drug-drug interactions", Scientific Data 9:72 (2022), published 2022-03-04. Article licence CC BY 4.0. [V; licence verified: <https://www.nature.com/articles/s41597-022-01159-y>]
- **Repository (resolved):** figshare collection <https://doi.org/10.6084/m9.figshare.c.5481408> ("5 Excel spreadsheets"). Code: <https://github.com/elpidakon/CRESCENDDI>. [verified: paper] Items and sizes via figshare API (<https://api.figshare.com/v2/collections/5481408/articles>): Data Record 1 Positive Controls (393,509 B), 2 Negative Controls (129,094 B), 3 Single-drug ADRs, indications and negative controls (1,979,074 B), 4 Drug mappings (237,380 B), 5 Event mappings (112,324 B). [verified: figshare API]
- **Licence (resolved):** every item is **CC0** (`https://creativecommons.org/publicdomain/zero/1.0/`). [verified: figshare API, per item] Corrected: first pass guessed "usually CC BY".
- **Sources (resolved):** DDIs from the BNF website, the French ANSM *Thesaurus des interactions médicamenteuses* (via the R package IMthesaurusANSM, 2019 update) and Micromedex. BNF and Micromedex were web-extracted June–August 2018. Single-drug ADRs from BNF and SIDER. [verified: paper, Methods]
- **Columns (resolved, checked in downloaded file):** Positive controls: `DRUG_1_CONCEPT_NAME, DRUG_2_CONCEPT_NAME, EVENT_CONCEPT_NAME, MDR_CODE, EVENT_SOURCE, BNF_SEV_LEVEL, ANSM_SEV_LEVEL, MICROMEDEX_SEV_LEVEL, BNF_EVID_LEVEL, MICROMEDEX_EVID_LEVEL`. Negative controls: the first four. Drug mappings: `DRUG_INITIAL_NAME, DRUG_CONCEPT_NAME, RXNORM_CODE/RXNORM_EXTENSION_CODE (OHDSI), SOURCE`. [verified: paper Data Records + Data Record 1 and 4 files]
- **Coding (resolved):** events are MedDRA **PT** names + MedDRA codes (e.g. Hyponatraemia `10021036`), MedDRA v19.1. Drugs are mapped to RxNorm / RxNorm Extension **ingredients** through the OHDSI vocabulary (v5.0, 18-JAN-19). The control files carry only the drug **names**. The only drug codes are in the drug-mapping file, and they are **OHDSI/OMOP concept IDs, not RxCUIs**. Example: bortezomib is `1336825` in the file, but RxNav gives RxCUI `358258`; nicardipine is `1318137` vs RxCUI `7396`. [verified: paper Code availability + file + RxNav] To join on RxCUI, map by ingredient name via RxNav, or use the OMOP `CONCEPT` table.
- **Counts (re-checked in file):** 10,286 positive rows; 454 distinct drugs (union of both columns, case-insensitive); 179 distinct events / MedDRA codes; **4,971 distinct unordered drug pairs**. [verified: file] Negative controls: 4,544 rows, 435 drugs, 161 events. [verified: paper]
- Granularity: **drug pair + specific adverse event**, the same shape as a Decagon triple (a, b, r). To compare with Decagon's side-effect IDs, MedDRA PTs must be mapped to Decagon's side-effect vocabulary [unverified: which vocabulary/mapping Decagon uses is not re-checked here].
- Independent of FAERS mining: positives come from BNF/ANSM/Micromedex. FAERS was used only for validation and to size the negative-control set. [verified: paper] Small drug coverage limits recall.

### TWOSIDES / nSIDES
- TWOSIDES (Tatonetti et al., Sci Transl Med 2012, doi:10.1126/scitranslmed.3003377, PMC3382018) is mined from FAERS. [verified: nsides.io + nSIDES v0.1 release notes] Decagon's combo labels being a filtered TWOSIDES is per this project's map (`3.4.1`) [unverified here]. The 2012 paper's counts [unverified: PMC returned a reCAPTCHA page; see Blockers].
- **Hosting (resolved):** <https://nsides.io> (Tatonetti Lab) links the files at <http://tatonettilab-resources.s3-website-us-west-1.amazonaws.com/?p=nsides/>. The bucket holds `TWOSIDES.csv.gz` (738,463,578 B), `TWOSIDES.csv.xz` (387,702,456 B), `OFFSIDES.csv.gz` (68,762,346 B), `OFFSIDES.csv.xz` (34,851,808 B), `effect_nsides-2019-11-13.sql.gz` (1.42 GB) and `README.txt`; all uploaded 2024-03-30. [verified: bucket listing `https://tatonettilab-resources.s3.amazonaws.com/?list-type=2&prefix=nsides/`]
- **Columns (resolved):** TWOSIDES: `drug_1_rxnorn_id` (sic), `drug_1_concept_name`, `drug_2_rxnorm_id`, `drug_2_concept_name`, `condition_meddra_id`, `condition_concept_name`, `A, B, C, D, PRR, PRR_error, mean_reporting_frequency`. Drug IDs are **RxCUIs**, events **MedDRA** codes. Each unordered pair appears once. Flat files keep only rows with A > 0 and PRR > 0.1. [verified: <https://tatonettilab-resources.s3.amazonaws.com/nsides/README.txt>, <https://github.com/tatonetti-lab/nsides-release/blob/master/release-notes/v0.1.md>]
- **Release v0.1 (resolved):** FAERS up to and including 2014; 3,394 drugs; 17,552 event types; 5,729,992 significant drug-drug-event triplets (significance `log(PRR) − 1.96·PRR_error > log(2)`), not filtered against single-drug signals. [verified: release notes] nsides.io says these resources are "quite a bit out of date". [verified: nsides.io]
- **Licence (resolved as "none stated"):** no licence or terms on nsides.io, in the bucket `README.txt`, or in `tatonetti-lab/nsides-release` (GitHub API: `license: none`). The separate code/web repo `tatonetti-lab/nsides` has a `LICENSE.txt` with CC BY-NC-SA 4.0. Whether that covers the data is not stated. [verified: GitHub API + LICENSE.txt] Treat the data as "free to download, licence unclear; ask the lab before redistributing".
- **Circularity:** using TWOSIDES as "documented" would mostly re-find FAERS signals of the kind Decagon was trained on; it is not independent clinical documentation.

### ONC high-priority DDI list
- Phansalkar et al., "High-priority drug-drug interactions for use in electronic health records", JAMIA 2012;19(5):735–743, doi:10.1136/amiajnl-2011-000612, PMC3422823. [verified: <https://pmc.ncbi.nlm.nih.gov/articles/PMC3422823/>]
- **Contents (resolved):** an expert panel reviewed 31 candidates and accepted 16. Linezolid–triptans was then dropped on knowledge-base vendor scores, leaving **15 DDIs "which represent drugs that should never be co-prescribed"**. The 15, with object–precipitant classes: amphetamine derivatives–MAO inhibitors; atazanavir–PPIs; febuxostat–azathioprine/mercaptopurine; SSRIs/serotonergic agents–MAO inhibitors; irinotecan–strong CYP3A4 inhibitors; narcotic analgesics (meperidine, methadone, tapentadol, fentanyl, tramadol, dextromethorphan)–MAO inhibitors; TCAs–MAO inhibitors; QT-prolonging–QT-prolonging agents (high-risk list from torsades.org); ramelteon–CYP1A2 inhibitors; strong CYP3A4 inducers–protease inhibitors; simvastatin/lovastatin–CYP3A4 inhibitors; CYP3A4 inhibitors–ergot alkaloids; tizanidine–CYP1A2 inhibitors; tranylcypromine–procarbazine; triptans (sumatriptan, zolmitriptan, rizatriptan)–MAO inhibitors. [verified: paper Results, Tables 2 and 4]
- Member lists are "suggested but not intended to represent every member in the drug class". Table 2 gives panel considerations, not a clinical-consequence column. Corrected: first pass said "+ clinical consequence text". Gemfibrozil–statins and others were demoted off the list. [verified: paper]
- A companion paper on low-priority / non-interruptive DDIs exists [unverified]. The NLM FAQ confirms RxNav used this list, supplemented by CredibleMeds' TdP-risk list. [verified: NLM FAQ]
- Licence: © 2012 BMJ Publishing Group; no open licence on PMC. Free to read; the 15 pairs are facts that can be re-coded by hand. [verified: PMC copyright notice]
- Granularity: drug class pair (contraindicated). Use as a **sanity check** for `7.1`, not as a coverage reference. Most NHANES top pairs (cardiovascular/metabolic) will not be on it except statin–CYP3A4 inhibitor and QT combinations.

### NLM RxNav Drug Interaction API
- NLM's RxNav FAQ: "RxNav's drug/drug interaction features were discontinued on January 2, 2024." The sources it drew from were the ONC high-priority list (supplemented with CredibleMeds' TdP list) and DrugBank's DDI dataset. [verified: <https://lhncbc.nlm.nih.gov/RxNav/information/FAQs.html>] This replaces the first-pass reliance on a search quote of the news page. The news page and the interaction API doc pages still return HTTP 403 (see Blockers).
- The APIs overview page lists as "currently available": RxNorm API, Prescribable RxNorm API, RxTerms API, RxClass API. No interaction API is listed. [verified: <https://lhncbc.nlm.nih.gov/RxNav/APIs/index.html>]
- Its data had been a limited DrugBank subset (no severity, no management) plus ONC High. [V] <https://blog.drugbank.com/nih-discontinues-their-drug-interaction-api/> (DrugBank is an interested party.)
- No NLM replacement was found. [verified: FAQ points only to the original sources]
- **RxNorm name/ID APIs still work (resolved):** the RxNorm API page lists `findRxcuiByString`, `findRxcuiById`, `getApproximateMatch`, `getRxNormName`, `getRxProperty`, `getAllRelatedInfo`, `getRxcuiHistoryStatus` as Active. [verified: <https://lhncbc.nlm.nih.gov/RxNav/APIs/RxNormAPIs.html>] Live tests on 2026-10-28, all HTTP 200: `rxcui.json?name=bortezomib` → 358258; `rxcui/358258/properties.json` → bortezomib, IN; `approximateTerm.json?term=simvastatin` → 36567; `rxcui.json?idtype=DRUGBANK&id=DB00641` → 36567. The old `REST/interaction/interaction.json?rxcui=341248` returns HTTP 404 "Not found". [verified: live requests]
- Terms: no licence needed (one exception); **max 20 requests/s per IP**, 100/s with a UMLS API key; cache 12–24 h recommended; RxNav-in-a-Box for heavy use. [verified: <https://lhncbc.nlm.nih.gov/RxNav/TermsofService.html>] The mapping backbone (`4.2`) is unaffected.

## Implications for `7.7` (facts, not decisions)

- No free source gives **side-effect-level** documentation at Decagon's scale except TWOSIDES, which is FAERS-derived and so circular.
- Pair-level "documented: yes/no (+ severity)" is available from DDInter at about 1.8k–2.3k drugs. The bulk CSVs (2021 data) **do include cardiovascular (C) and nervous-system (N) files**, so the NHANES-coverage concern from the first pass falls away. Coverage of Decagon's 645 drugs after mapping is not measured. DDInter 2.0's extra records are web-only.
- Side-effect-level documentation is available only for CRESCENDDI's 454 drugs / 179 events / 4,971 pairs (CC0).
- Licences: DDInter CC BY-NC-SA 4.0 (non-commercial, share-alike); DrugBank academic CC BY-NC 4.0; KEGG academic-only API; CRESCENDDI CC0; SIDER CC BY-SA 4.0; nSIDES data no stated licence. Corrected: first pass said all were non-commercial.
